# מטלות — אפליקציית מעקב מטלות לילדים

**תאריך:** 2026-08-03
**ריפו:** https://github.com/Haimyegudis/Matalot.git
**סטטוס:** מאושר ע"י המשתמש

## מטרה

אפליקציית אנדרואיד משפחתית למעקב אחרי מטלות של שני ילדים (יודעים לקרוא), עם סנכרון בין כל טלפוני המשפחה, מצב הורה ומצב ילד. מעקב בלבד — לא אכיפה. ניקוד שבועי, בונה אוואטר, התראות.

## החלטות מוצר (מאושרות)

- **משתמשים:** 2 ילדים (קוראים) + הורים. לכל ילד טלפון משלו; גם טלפוני ההורים.
- **כניסה:** התקנה חד-פעמית בכל מכשיר (התחברות לחשבון המשפחה), בחירת פרופיל שנשמרת מקומית. מצב הורה מוגן ב-PIN.
- **מטלות:** משותפות (מי שעושה — מקבל את הנקודה) או משויכות לילד מסוים. הורה מוסיף/עורך/מוחק.
- **ניקוד:** נקודות לכל מטלה (ברירת מחדל 1, ההורה קובע). נספרת מיד בלחיצה; הורה יכול לבטל. שבוע: ראשון–שבת.
- **מקלחת:** מטלה מיוחדת — מעקב מי התקלח ומתי, סדר לפי שעת סימון, והצגת "הערב ראשון: X" (מי שהיה שני אתמול — תור מתחלף).
- **משימות חד-פעמיות:** הורה מוסיף משימה לילד + שעת תזכורת. הילד מקבל התראה ומאשר ביצוע. ההורה מקבל התראה על כל ביצוע (מטלה או משימה).
- **אוואטר:** בונה אוואטר SVG שכבות (עור, שיער, עיניים, בגדים, אקססוריז) או העלאת תמונה.
- **הפצה:** PWA על Vercel + עטיפת TWA ל-APK בהתקנה ידנית (כמו WorkDiary). עדכוני אפליקציה מיידיים דרך הווב.

## ארכיטקטורה

- **Frontend:** React + Vite + TypeScript, עברית RTL, PWA (service worker, manifest).
- **Backend:** פרויקט Supabase חדש ונפרד (לא של WorkDiary): Postgres + Auth + Realtime + Edge Functions + Storage (תמונות פרופיל).
- **Auth:** חשבון Supabase Auth אחד למשפחה (אימייל+סיסמת הורה). כל מכשיר מתחבר פעם אחת. RLS מסנן לפי משפחה. PIN הורה — hash ב-DB, שער בצד לקוח (מספיק נגד ילדים, לא אבטחה קשיחה).
- **פריסה:** Vercel (פרויקט חדש). TWA APK עם keystore חדש, מגובה ב-`C:\APPS\keys`.

## מודל נתונים

| טבלה | שדות |
|---|---|
| `families` | id, name, parent_pin_hash, owner_uid |
| `profiles` | id, family_id, name, role (`parent`/`child`), avatar (JSONB שכבות), photo_url, color |
| `chores` | id, family_id, title, icon, points (ברירת מחדל 1), assigned_to (profile_id, NULL=משותפת), is_shower (bool), active (bool), sort |
| `completions` | id, chore_id, profile_id, completed_at (timestamptz), day (date), revoked_by (profile_id, NULL=בתוקף) |
| `tasks` | id, family_id, child_id, title, icon, points, remind_at (timestamptz), status (`pending`/`done`), completed_at |
| `push_subscriptions` | id, profile_id, endpoint, keys (JSONB), device_label |

**כללים:**

- ניקוד שבועי = סכום `points` של completions לא-מבוטלות + tasks שהושלמו, בין ראשון 00:00 לשבת 23:59 (זמן ישראל), מחושב בצד לקוח.
- אינדקסים ייחודיים חלקיים (על completions בתוקף בלבד):
  - מטלה משותפת (assigned_to=NULL, לא מקלחת): unique `(chore_id, day)` — הראשון זוכה; מכשיר שני מקבל הודעה עדינה "X כבר עשה את זה".
  - מטלה משויכת וגם מקלחת: unique `(chore_id, day, profile_id)` — ביצוע אחד ליום לילד.
- מקלחת (`is_shower`, assigned_to=NULL): כל ילד מסמן בנפרד כל ערב. סדר = `completed_at`. "הערב ראשון" = מי שהיה שני אתמול; אם אין נתון מאתמול — לפי סבב אחרון ידוע, אחרת לא מוצג.
- מחיקת מטלה = `active=false`; ההיסטוריה נשמרת.
- ביטול הורה: כתיבת `revoked_by`; הנקודה יורדת רטרואקטיבית (הלוח תמיד נגזר מהנתונים).

## מסכים

### ילד (ברירת מחדל)

1. **בחירת פרופיל** — בהפעלה ראשונה במכשיר: כרטיסי אוואטר גדולים. נשמר מקומית.
2. **בית "היום"** — רשת כפתורים גדולים עם אייקון לכל מטלה. לחיצה = אנימציית הצלחה + נקודה. משותפת שבוצעה ע"י אח — אפורה עם "בוצע ע"י X". כרטיס מקלחת עם "הערב ראשון: X 🚿". משימות מההורה עם שעה — למעלה עם badge. פס ניקוד שבועי של שני הילדים.
3. **"אתמול"** — אותו מסך, קריאה בלבד.
4. **יומן** — לוח חודשי: נקודות ליום, פירוט בלחיצה.
5. **פרופיל** — בונה אוואטר בטאבים (עור/שיער/עיניים/בגדים/אקססוריז) או העלאת תמונה.

ניווט: 3 טאבים תחתונים — היום / יומן / פרופיל. אייקון מנעול קטן בפינה → מצב הורה.

### הורה (אחרי PIN)

1. **לוח שבועי** — ימים × ילדים, מי עשה מה, סכומי נקודות. לחיצה על ביצוע → ביטול.
2. **ניהול מטלות** — הוספה/עריכה/השבתה: שם, אייקון ממאגר מובנה, נקודות, שיוך.
3. **משימה חדשה** — ילד + כותרת + שעת תזכורת.
4. **הגדרות** — פרופילים, שינוי PIN.

## סנכרון והתראות

- **Realtime:** מנויים על `completions`, `chores`, `tasks` — עדכון בין מכשירים תוך ~שנייה.
- **Offline:** לחיצות נשמרות בתור מקומי (localStorage) ונשלחות בחזרת חיבור; חיווי "ממתין לסנכרון". התנגשות עם unique constraint → הודעת "X כבר עשה" וביטול מקומי.
- **Web Push (VAPID):** בקשת הרשאה בהתקנה, שמירת subscription פר מכשיר-פרופיל.
  - תזכורות: `pg_cron` כל דקה → Edge Function שולחת push לילד על משימות שהגיע זמנן. לחיצה על ההתראה פותחת את המשימה.
  - ביצוע: trigger/edge function → push להורים ("דני ביצע: הוצאת זבל 🎉").
  - מגבלה ידועה: Web Push תלוי בכך שאנדרואיד לא הקפיא את כרום — עובד ברוב המכשירים.
