# עיצוב: מטלה להיום עם שעה, בחירת ילד בהוספה מהרשימה, "מי התקלח ראשון אתמול"

תאריך: 2026-08-03

## רקע

שלוש בקשות מההורה:

1. בהוספת מטלה מהרשימה ("➕ להיום") אין דרך להוסיף לילד ספציפי — המטלה מופיעה לשניהם.
2. ב"מתי מופיעה" (גיליון עריכת מטלה, כלי הורה) אין אפשרות "היום" עם שעה. ההורה רוצה
   להוסיף מטלה להיום בשעה מסוימת, ולציין **באותו גיליון** אם צריך התראה ומתי —
   לא בטאב ההתראות הנפרד.
3. בכרטיס המקלחת: להציג תמיד מי התקלח ראשון אתמול.

## 1. בחירת ילד בהוספה מהרשימה (day_picks לפי ילד)

### DB — מיגרציה `0012_pick_child_remind.sql`

- `day_picks.child_id uuid null references profiles(id) on delete cascade` — null = שניהם.
- `day_picks.remind_at timestamptz null`, `day_picks.reminded_at timestamptz null` (לפיצ'ר 2).
- להחליף את `unique (chore_id, day)` ב-`unique nulls not distinct (chore_id, day, child_id)`.

### UI — `KidHome.tsx`, גיליון "רשימת מטלות"

- הורה: בכל שורת מטלה בקטלוג, במקום כפתור "➕ להיום" יחיד — שלושה כפתורים:
  **שניהם / [ילד א] / [ילד ב]** (לילדים מוקצים־מראש רק הכפתור הרלוונטי).
- ילד: כפתור "להיום" יחיד כמו היום (child_id = null).

### סינון בלוח — `KidHome.tsx`

- pick נראה לילד אם `child_id === null || child_id === me.id` (הורה רואה הכול).
- מטלה נשארת בקטלוג של ילד שאין לו pick עליה היום — אפשר להוסיף גם לו בנפרד.
- הבחירה תופסת רק ליום הזה. `assigned_to` (שיוך קבוע) לא משתנה.

## 2. "היום" + שעה + התראה בגיליון המטלה

### UI — `ManageChores.tsx`

- ב"מתי מופיעה" מצב רביעי: **היום**.
- בבחירת "היום" מופיע שדה שעה אופציונלי (`input type="time"`): "⏰ תזכורת בשעה (אופציונלי)".
- שמירה: המטלה נשמרת עם `days: []` (קטלוג) + מחיקת picks קיימים של המטלה להיום
  והוספת pick חדש (מונע כפילות כששיוך/שעה משתנים):
  `child_id` = `assigned_to` של המטלה (או null אם משותפת), `remind_at` = היום+שעה אם נבחרה.
- בעריכת מטלה שיש לה pick להיום — המצב "היום" מוצג כנבחר והשעה נטענת.

### תצוגה בלוח — `ChoreButton`

- אריח עם pick שיש לו `remind_at` והמטלה עוד לא בוצעה: שורה "⏰ עד HH:MM"
  (כמו במשימות).

### פוש — `supabase/functions/remind-due/index.ts`

- שאילתה שלישית: `day_picks` עם `remind_at <= now()`, `reminded_at is null`, join לשם המטלה.
- claim של `reminded_at` לפני שליחה (כמו tasks).
- נמענים: `child_id` אם קיים, אחרת שני הילדים. דילוג אם המטלה כבר הושלמה היום ע"י הנמען.
- תוכן: "⏰ תזכורת ממטלות" / שם המטלה.

## 3. מקלחת — מי התקלח ראשון אתמול

### לוגיקה — `logic.ts`

- helper חדש `showerFirstOn(completions, choreId, day)` → profile_id של הראשון באותו יום, או null.

### UI — `ShowerCard.tsx`

- שורה קבועה (תמיד, גם אחרי מקלחות של היום):
  - יש נתון מאתמול: "אתמול מיה התקלחה ראשונה 🚿" (עם הטיה לפי מגדר, `g()`).
  - אין מאתמול אך יש יום קודם: "בפעם הקודמת X התקלח ראשון".
  - אין בכלל: לא מוצג.
- ההצעה "הערב ראשונה: Y" נשארת כמו שהיא.
